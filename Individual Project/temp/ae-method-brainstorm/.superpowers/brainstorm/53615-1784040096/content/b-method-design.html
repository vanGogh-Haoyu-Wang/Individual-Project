方案 B：迁移 + 小改进

目标不是立刻做复杂材料分类，而是做一条你能理解、能运行、能比较的 AE 分析流程。

两阶段实验
阶段 1：忠实迁移

基础 Peak Frequency

.mat 原始波形 → 事件检测 → FFT → 每事件 1 个最强频率 → 原有三张图

目的：确认 Python / Julia 都能复现现有 MATLAB 方法。

→
阶段 2：小改进

Top-3 Frequency

同一个事件不只保留最强频率，而是保留最强的 3 个、且彼此至少相隔 20 kHz 的频率。

目的：检查单一峰值是否会掩盖次要频率成分。

每个原型的输入与输出

输入
  • .mat：原始 AE 波形，是真正做 FFT 的来源
  • .xlsx / .csv：机械应力、应变和已有 AE 摘要，用来画对照图和核对时间
输出
  • 事件表：事件时间、Top-1 / Top-2 / Top-3 频率及幅值
  • 基础图：时间 vs Top-1 峰值频率
  • 改进图：时间 vs Top-3 峰值频率
  • 可复现结果：CSV、PNG、运行说明

不在本轮声称的事情

不把频带自动说成钢的裂纹类型；不先做机器学习；不假装 Top-3 一定“更准确”。本轮只检验：它是否保留了 Top-1 忽略的频率信息。
