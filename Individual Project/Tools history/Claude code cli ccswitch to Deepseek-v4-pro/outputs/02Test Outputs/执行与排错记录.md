## 逐步问题、根因与解决办法

### 1. 首次运行：缺少 matplotlib

原样执行脚本后，在第 14 行导入阶段退出：

```text
ModuleNotFoundError: No module named 'matplotlib'
```

根因：工作区 Python 有 pandas/openpyxl，但没有 matplotlib；系统的 Homebrew Python 又缺少 pandas，不能直接换用。

解决：给工作区 Python 单独安装 matplotlib 到临时目录，并通过 `PYTHONPATH=/private/tmp/ae_analysis_deps` 加载。这样既能复用已有 pandas/openpyxl，也不会修改项目依赖。

### 2. 第一次安装依赖：沙箱内无法访问 PyPI

第一次安装出现 DNS/网络错误：

```text
Failed to establish a new connection: [Errno 8] nodename nor servname provided
ERROR: Could not find a version that satisfies the requirement matplotlib
```

根因：默认沙箱禁止外网，不是包名或 Python 版本错误。

解决：取得联网许可后重试同一条安装命令，成功安装 matplotlib 3.11.0 及其绘图依赖。

### 3. 第二次运行：Matplotlib 默认缓存目录不可写

运行时出现警告：

```text
mkdir -p failed for path /Users/vangogh/.matplotlib: [Errno 1] Operation not permitted
Matplotlib created a temporary cache directory ...
```

根因：当前文件系统权限不允许写入用户主目录下的 `.matplotlib`。

影响：这不是绘图失败的直接原因，但会反复重建字体缓存，拖慢运行并产生不稳定的临时路径。

解决：显式设置 `MPLCONFIGDIR=/private/tmp/ae_matplotlib_config`，使用确定且可写的缓存目录；同时使用 `Agg` 后端，避免 `plt.show()` 等待图形界面。

### 4. 第二次运行的实际崩溃：Excel 表头被当作数据

依赖问题解决后，脚本在第一张图的 `ax1.plot(...)` 崩溃：

```text
TypeError: 'value' must be an instance of str or bytes, not a float
```

根因：原脚本使用：

```python
pd.read_excel(FILE_PATH, sheet_name=SHEET, header=None)
```

但 `CT07` 顶部实际有 3 行非数据内容：

1. AE 列标题；
2. 拉伸试验列标题（如 `Test time`、`Strain`、`Stress`）；
3. 单位行（如 `s`、`%`、`MPa`）。

因此同一个 NumPy 数组混合了字符串与浮点数，Matplotlib 在判断坐标类型时失败。

解决：按索引读取的逻辑不变，但使用 `header=None, skiprows=3` 跳过 3 行非数据内容，并对 8 个目标列执行数值转换。

### 5. 清除表头后仍有潜在崩溃：两个通道长度不同

诊断结果：

- 力学通道 `test_time / strain / stress` 只有前 1807 行有效；
- AE 通道 `time / RMS / cumulative RMS / energy / cumulative energy` 有 5848 行有效；
- Excel 为了把两种采样长度放在同一张表中，在力学列尾部留下了 4041 个空单元格。

原脚本把所有列放进同一个 5848 行数组，并调用 `stress.max()`。NumPy 数组含 `NaN` 时，结果会是 `NaN`，后续 `set_ylim(0, NaN)` 会报坐标轴范围错误。

解决：分别构造两张有效数据表：

- `mechanical`：只保留 `test_time / strain / stress` 同时非空的 1807 行；
- `acoustic`：只保留 5 个 AE 字段同时非空的 5848 行。

各图继续使用正确的通道组合，力学纵轴上限改由清理后的 `mechanical["stress"].max()` 计算。

### 6. 原脚本只显示窗口，不会输出图片文件

原脚本末尾只有 `plt.show()`，即使绘图成功，也不会在 `outputs/02Test Outputs` 中产生 PNG；在无界面环境中还可能直接返回或等待窗口。

解决：为 5 个 Figure 分别执行：

```python
fig.tight_layout()
fig.savefig(output_path, dpi=200, bbox_inches="tight")
plt.close(fig)
```

并给文件加上 `01` 到 `05` 的稳定序号。

### 7. 原脚本不能接收绝对输入路径和输出目录

原脚本把数据库写成相对路径 `Commercial Tensile Tests.xlsx`，且没有输出目录参数。

解决：修正版增加：

```text
--input <数据库绝对路径>
--output-dir <结果目录绝对路径>
```

正式运行日志确认使用的是用户指定的绝对数据库路径。

### 8. 图 2 标题与实际工作表不一致

原脚本读取 `CT07`，但图 2 标题硬编码为 `T09 Commercial Normalised RMS Profile`，容易造成结果归属误判。

解决：所有标题统一由 `SHEET = "CT07"` 生成，图 2 最终标题为 `CT07 Commercial Normalised RMS Profile`。
