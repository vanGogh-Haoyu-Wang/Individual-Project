## 遇到的问题与处理过程

### 1. Python 环境缺少 Matplotlib

- 首次运行在脚本第 18 行失败：`ModuleNotFoundError: No module named 'matplotlib'`。
- 此时脚本尚未读取 Excel，说明第一个根因是运行环境依赖缺失，而不是数据库路径或工作表错误。
- 核查结果：指定的捆绑 Python 已有 `pandas 2.2.3` 和 `openpyxl 3.1.5`，但没有 `matplotlib`；系统 Homebrew Python 连 pandas 也没有，因此不能直接替换解释器。
- 解决：将 `matplotlib 3.11.0` 及其依赖隔离安装到 `outputs/02Test Outputs/.python_packages`，运行时通过 `PYTHONPATH` 加载。没有改动系统 Python，也没有污染全局 site-packages。

### 2. 受限网络导致第一次依赖安装失败

- 沙箱内执行 pip 时 DNS 不可用，连续重试后返回：`Could not find a version that satisfies the requirement matplotlib`。
- 这个报错并非 PyPI 没有 Matplotlib，而是前面的 `Failed to establish a new connection` 导致索引不可达。
- 解决：按权限流程允许联网后重试同一条隔离安装命令；成功下载缓存的 macOS arm64 wheel 并安装全部依赖。

### 3. Excel 机械数据列混合文字与数字，第一张图报类型错误

- 安装依赖后，脚本成功读取 `CT07`，但在第 127 行 `ax1.plot(strain, stress, ...)` 失败：`TypeError: 'value' must be an instance of str or bytes, not a int`。
- 稳定复现后检查工作表：pandas 读到 5,850 行、15 列。第 0、2、3 列被推断为 `object`，因为数据开头仍有两行内部标签：
  - 第 0 列：`Test time`、`s`
  - 第 2 列：`Strain`、`%`
  - 第 3 列：`Stress`、`MPa`
- 同一工作表的 AE 时间及 AE 指标列从首行就是有效数值。若直接删除前两整行，会错误丢掉两条 AE 数据，因此不能整行裁剪。
- 解决：只对 `t1`、`strain`、`stress` 三个机械列使用 `pd.to_numeric(..., errors="coerce")`。内部文字标签被转换为 `NaN`，Matplotlib 会跳过这些点；AE 数据列保持完整。

### 4. 原脚本只调用 `plt.show()`，不会生成图片文件

- 原脚本能创建 5 个 figure 对象，但结尾只有 `plt.show()`。在桌面交互环境中它只弹窗，在无界面 `Agg` 后端中不会保存任何结果。
- 先建立自动验收脚本 `test_ae_outputs.py`：要求主脚本退出码为 0，输出文件名与预期 5 项完全一致，并要求每个文件大于 10 KB。修改前测试因上述数据类型错误而失败，证明测试确实覆盖原始故障。
- 解决：为 5 个 figure 分配固定、可排序的文件名，调用 `figure.savefig(..., dpi=300, bbox_inches="tight")`，全部写入指定绝对目录。

### 5. 无界面后端调用 `plt.show()` 产生警告

- 图片已能生成，但正式运行出现：`UserWarning: FigureCanvasAgg is non-interactive, and thus cannot be shown`。
- 这是非阻塞警告，不过会让自动运行日志不干净。
- 先扩展测试，明确要求标准错误中不得出现 `UserWarning`；测试按预期失败。
- 解决：保存后检查 Matplotlib 后端。使用 `Agg` 时执行 `plt.close("all")`；交互式后端仍保留 `plt.show()`。修复后测试再次通过，运行无警告。

### 6. 图 2 标题中的 T09

- 图 2 标题是 `T09 Commercial Normalised RMS Profile`，而数据库工作表是 `CT07`，其他图也写 T07。
- 原脚本注释已明确说明这是从 MATLAB 原脚本保留的疑似复制粘贴不一致。为了不擅自改变分析语义，本次原样保留，并将其记为非阻塞注意事项。
