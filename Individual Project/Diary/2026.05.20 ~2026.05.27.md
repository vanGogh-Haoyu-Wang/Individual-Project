# 2. Project Toolset Overview

### **Overview of Installed Tools: Framework for Scientific Code Migration and AI-Assisted Development**

The core objective of this project is to migrate the UoB-NDT group's MATLAB acoustic emission analysis code to an open-source Python environment. To achieve this, a comprehensive toolchain has been established, comprising traditional transpilers, cloud-based Large Language Model (LLM) agents, and privacy-focused local models:

1. **SMOP (Small MATLAB/Octave to Python)**:
   Serving as the foundational **transpiler**, SMOP is utilised for the initial "syntactic translation." It automatically maps MATLAB's function structures and loop logic into Python. This generates an initial code skeleton for subsequent human-AI collaborative optimisation, significantly reducing the manual effort required to rewrite basic architectures.

2. **Claude Code (Anthropic)**:
   Deployed as an **agentic development tool**. Leveraging its advanced logical reasoning capabilities, Claude Code is primarily used to handle complex refactoring tasks during the migration, such as converting procedural MATLAB logic into object-oriented Python structures. It also assists in writing unit tests to strictly verify "functional equivalence."

3. **Gemini (Google)**:
   Utilising its **extended context window**, Gemini is tasked with the comprehensive architectural analysis of the extensive legacy MATLAB codebase. It excels at explaining complex matrix operations and generating detailed control-flow diagrams, directly supporting the requirements analysis and architectural mapping in Phase 1 of the project.

4. **Ollama / LM Studio (Integrated with Hugging Face Models)**:
   This constitutes the **privacy and research core** of the project. By running open-source models (such as Llama 3 or Gemma) locally via Hugging Face, it ensures that sensitive research data and internal algorithms are processed without the risk of cloud exposure, directly addressing the project's "data confidentiality" requirements. Furthermore, it serves as an experimental control group to evaluate and compare the code translation quality between open-source and commercial models.

5. **Codex (OpenAI / IDE Assistant)**:
   Integrated directly into the VSCode environment as a **real-time coding assistant**. During the manual fine-tuning of the Python code, Codex provides instantaneous syntax suggestions and NumPy vectorisation completions, significantly enhancing the efficiency of converting raw translated code into high-performance, optimised scripts.

**Summary**: This toolchain comprehensively covers the entire workflow—from mechanical translation and logical reasoning to privacy protection. It strictly aligns with the high standards required for reproducibility, transparency, and security (FAIR principles) in scientific computational migrations.

# 3. Summary of AI Platforms and Models Used

In addition to the local development toolchain, this project leverages a diverse suite of Large Language Models (LLMs) and cloud-based AI platforms to facilitate the translation, debugging, and optimisation of the MATLAB code. These platforms are categorised into commercial models and university-provided pilot models, serving distinct roles in the comparative research phase:

1. **OpenAI Platforms (ChatGPT 5.3 & 5.2)**:
   - **ChatGPT 5.3 (Commercial)**: Utilised for advanced code generation and troubleshooting. Its robust understanding of both MATLAB and Python/Julia paradigms makes it a primary engine for translating complex algorithms.
   - **ChatGPT 5.2 (UoB AI Pilot)**: Used as a baseline model within the university's approved AI sandbox, ensuring compliance with institutional data guidelines while providing reliable general-purpose coding assistance.

2. **DeepSeek-AI (DeepSeek 3.2)**:
   - Recognised for its exceptional proficiency in coding tasks and mathematical reasoning, DeepSeek 3.2 is employed to handle highly specialised numerical computations and matrix transformations. It serves as a strong comparative benchmark against mainstream Western models for scientific software translation.

3. **Anthropic Claude Suite (Sonnet 4.6 & Opus 4.6)**:
   - **Claude Sonnet 4.6 (Commercial)**: Chosen for its speed and precise instruction-following capabilities, making it ideal for iterative prompting and rapid code refactoring tasks.
   - **Claude Opus 4.6 (UoB AI Pilot)**: Leveraged for high-level architectural planning and intricate problem-solving. Its deep reasoning capabilities are critical during Phase 3 (Validation) for identifying subtle logical discrepancies between the MATLAB original and the Python translation.

4. **Meta Llama 4 Maverick (UoB AI Pilot)**:
   - Accessed via the university's pilot programme, this state-of-the-art open-source model is used to explore the capabilities of open-weight LLMs in scientific coding. It provides vital data points for evaluating the trade-offs between proprietary and open-source models in academic workflows.

5. **Google Gemini 3 Flash**:
   - Deployed for tasks requiring the processing of large volumes of documentation or extensive codebase contexts, owing to its efficiency and large context window.

**Summary**: The strategic combination of these platforms allows for a robust, multi-model approach. By comparing the outputs of ChatGPT, DeepSeek, Claude, and Llama, the project not only ensures the accurate translation of the acoustic emission framework but also rigorously evaluates the performance, risks (e.g., hallucinations), and practical utility of various LLMs in higher education and scientific computing.
